# Aditya Kumar — Dynamic Developer Portfolio

A responsive neon/terminal-inspired portfolio built with semantic HTML, CSS and JavaScript.

## Features
- Animated network background, typewriter roles, skill ticker and scroll progress
- Profile photo with animated technology orbits
- About, education, skills, projects, statistics, credentials and contact sections
- Live GitHub profile/repository metrics using the public GitHub API
- LeetCode dashboard using a public profile endpoint with a truthful 200+ fallback
- GitHub contribution calendar, downloadable CV and responsive mobile navigation

## Run locally
Open `index.html`, or run `python -m http.server 5500` and visit `http://localhost:5500`.

## Deploy to Vercel
Upload this folder to a GitHub repository, import it in Vercel, select framework preset **Other**, leave the build command empty, and use `.` as the output directory.

Only projects and achievements belonging to Aditya are included. Live dashboard services may occasionally fall back to cached/profile-summary values if a third-party API is unavailable.
